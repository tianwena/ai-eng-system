name: research
description: 针对高可信的一手资料调研一个问题，并把结论作为一个 Markdown 文件捕获到仓库里。当用户想研究某个话题、收集文档或 API 事实，或把阅读的跑腿活外包给一个后台 agent 时使用。（Investigate a question against high-trust primary sources and capture the findings as a Markdown file in the repo. Use when the user wants a topic researched, docs or API facts gathered, or reading legwork delegated to a background agent.）
---

起一个**后台 agent** 去做这项研究，这样它读的时候你还能继续干活。

它的任务：

1. 针对**一手资料**调研这个问题——官方文档、源代码、规格、官方 API——而不是别人对它们的二手转述。把每一条主张都追溯回拥有它的那个来源。
2. 把结论写进**单个** Markdown 文件，每条主张都标注来源。
3. 存到仓库已经在放这类笔记的地方；匹配既有约定，如果没有约定，就放在某个合理的地方并说明放在哪。
