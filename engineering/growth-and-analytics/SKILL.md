你在把**真实用户的行为**变成**下一步该做什么**。

**第一原则：埋点必须在上线前就位。** 上线后才发现没数据，等于白白浪费第一批真实用户——他们是**最贵也最有信息量**的一批。

---

## 一、先定北极星指标

北极星指标 = **一个能代表"用户真的获得了价值"的数字**。

> ⚠️ **别急着收成"一个"——阶段不同，该看的东西不同。**

| 阶段 | 该盯什么 | 为什么 |
|---|---|---|
| **上线前 / 极早期**（还没几个真实用户） | **验证性指标**：多少人说"愿意买"、多少人已经在用土办法解决、多少条 L3+/L4 证据 | 这时留存、北极星**都还测不出意义**（样本太小、噪声压过信号）。**盯一个统计上无意义的数字比不盯更糟** |
| **有几十个真实用户后** | **留存 + time-to-value** 两条一起看 | 留存是底线；time-to-value 决定你会不会优化错地方 |
| **留存曲线走平之后** | 才收成**一个**北极星指标 + 1~2 个辅助指标 | 这时"一个"才有意义：它让全队对齐 |

**成熟期**的北极星要满足三条判据（三条都要）：

1. **反映价值**：它涨，说明用户真的得到了东西（不是"我们做了动作"）
2. **可影响**：你的工作能推动它（不是纯外部因素）
3. **能领先收入**：它涨之后收入会涨（不是滞后指标）

**辅助指标**（配 1~2 个就够）：**留存率**（最重要）、**付费转化率**、**CAC / 回本周期**。

**反模式**：成熟期同时盯 10 个指标 = 没有指标；**但早期只盯一个北极星** = 用噪声做决策。

| ❌ 不是北极星 | ✅ 可能是北极星 |
|---|---|
| 注册数 | 完成核心动作的用户数 |
| 访问量 / PV | 每周完成核心动作 ≥1 次的用户数 |
| 下载量 | 付费用户的周活跃数 |
| 功能使用次数 | 被处理/被解决的单位数 |

**判据（三条都要满足）**：
1. **反映价值**：它涨，说明用户真的得到了东西（不是"我们做了动作"）
2. **可影响**：你的工作能推动它（不是纯外部因素）
3. **能领先收入**：它涨之后收入会涨（不是滞后指标）

**辅助指标（配 1~2 个就够）**：
- **留存率**（最重要——没有留存，增长是漏水的桶）
- **付费转化率**
- **获客成本 CAC** / **回本周期**

**反模式**：同时盯 10 个指标 = 没有指标。

## 二、埋点设计（做对一次，省半年）

### 事件命名规范（先定好，否则数据会烂）

```
<对象>_<动作>      例如：order_created / report_exported / plan_upgraded
属性用 snake_case，值用稳定的枚举（不要自由文本）
```

### 每个事件必须带的基础属性

```
user_id（匿名时用匿名 id）
timestamp（UTC）
session_id
来源（首次从哪来：utm / referrer）
版本（客户端/后端版本——否则你分不清"行为变了"还是"代码变了"）
```

### 必埋的关键事件（最小集）

```
① 到达（landing_viewed）——按来源分组
② 注册开始 / 注册完成（看清流失在哪一步）
③ 【核心动作】完成 —— 北极星的原料，最重要
④ 关键门槛事件（第一次成功、第一次导出、第一次邀请别人）
⑤ 付费相关：升级页浏览 → 结账开始 → 付款成功 / 失败
⑥ 错误与放弃（提交失败、超时、主动取消）
⑦ 流失信号（连续 N 天未活跃）
```

**关键动作要埋"开始"和"完成"两个点**——**只看"完成"的话，你不知道中间卡了多少人。**

**隐私红线**：不埋敏感数据（密码、卡号、身份证、私密内容）。事件属性里不要塞自由文本（用户可能输入个人信息）。

## 三、漏斗分析（找出漏得最狠的那一段）

把用户路径画成漏斗，**每一段看转化率**：

```
访问 → 注册开始 → 注册完成 → 首次核心动作 → 重复使用 → 付费 → 续费
 100%     ?           ?            ?            ?        ?      ?
```

**方法**：只看**相邻两段的转化率**，找**绝对值最低**的那一段——那里是你的瓶颈。

| 瓶颈位置 | 通常是这类问题 |
|---|---|
| 访问 → 注册开始 | 价值主张没说清 / 首屏没让人看懂 |
| 注册开始 → 完成 | 表单太长 / 要验证太多 / 报错看不懂 |
| 注册 → 首次核心动作 | **首次体验太长（最致命）** —— 用户还没看到价值就走了 |
| 首次 → 重复使用 | 没形成习惯 / 没有回来的理由 / 忘了 |
| 重复 → 付费 | 免费够用 / 价值感知不足 / 定价错位 |

**最重要的一环**：**首次核心动作的"到达时间"（time-to-value）**。
把它从 30 分钟压到 3 分钟，效果通常好过做十个新功能。

## 四、留存分析（增长的真实底线）

**留存 = 有多少人回来了。** 没有留存，拉新只是往漏桶里倒水。

### 队列留存（cohort retention）

```
按注册周分组，看每组在第 1/7/14/30 天还有多少人活跃

       D1    D7    D14   D30
W1    45%   22%   15%   12%
W2    52%   28%   19%   —
W3    48%   25%   —     —
```

**看点**：
- **曲线是否走平**（走平 = 有一批真实核心用户；持续下滑到 0 = 产品没抓住人）
- **新队列是否比旧队列好**（好 = 你的改动在起作用）

### 流失分析

> ⚠️ **别去问"他走之前的最后动作是什么"——那是终点归因，会稳定地把你引到错的地方。**
> 最后动作往往**没有信息量**：关标签页、退出登录、清缓存。**它是离开的动作，不是离开的原因。**

**正确的三个方向**：

1. **找"退化的起点"，不是终点**
   对比流失用户与留存用户在同一阶段（比如首周）的**行为序列**，问：
   **他从哪一步开始"少做了一件事"？**
   - 是不是**没到达首次价值**（卡在 time-to-value 之前）→ 修上手路径
   - 是不是到达了、但**没有回来的理由**（没有周期性价值）→ 修价值主张或加触发
   - 是不是**用了替代方案**（导出行为、客服提问）→ 产品缺口

2. **主动问，但别问"为什么不用了"**
   给流失用户发一封**一句话**的短信/邮件——**这是最便宜的高价值信息**。
   - ✅ 好问法：「你上次用是 X 号，能告诉我**那天你想做什么、卡在哪一步**吗？」
   - ❌ 坏问法：「你为什么不用了？」→ 得到的都是礼貌性借口（"最近比较忙"）
   - **问"那一天"**：把回忆锚定到具体场景，答案才有信息量

3. **分群对比**：留下来的和走掉的，在**哪一步**行为不同？那个差异点就是你的改进点。

**反模式**：
- 只看总活跃数（拉新多会掩盖留存崩坏）
- 拿最后动作当归因（**这一条会把优化火力全打错地方**）
- 只看流失率不做分群（平均值会掩盖"某一类人全走了"）

## 五、获客渠道评估

| 渠道 | 何时值得做 | 判断指标 |
|---|---|---|
| **口碑/推荐** | 产品真的好用 | 推荐带来的用户留存更高（通常最优质） |
| **内容/SEO** | 用户在搜这个问题 | 长尾流量、慢但复利 |
| **社区/垂直社群** | 目标人群聚集 | 转化率高，但要真诚参与，不能只发广告 |
| **付费广告** | **单位经济为正时** | CAC < 回本周期内能收回的成本 |
| **冷启动外联** | 早期 B2B | 转化率最高，但不可规模化 |
| **平台/应用市场** | 有平台生态 | 依赖平台政策，注意风险 |

**铁规**：**渠道要看"留存后"的成本，不是"注册"的成本。**
一个 CAC ¥10 但留存 5% 的渠道，比 CAC ¥50 但留存 40% 的渠道**贵得多**。

```
有效 CAC = 渠道花费 ÷ 该渠道带来的【留存用户数】
只投：有效 CAC < 该用户生命周期毛利
```

## 六、把数据变成动作（否则分析就是自我娱乐）

每轮分析产出一张**动作表**，不超过 3 项：

```markdown
# 增长分析 — <日期>

## 北极星
<指标> 本周 <值>（上周 <值>，变化 <±%>）

## 最大瓶颈
漏斗第 <N> 段：<阶段名>，转化率 <x>%（上一段 <y>%）

## 证据
- 数据：<具体查询结果>
- 定性：<用户原话 / 流失访谈摘录>

## 下一步（≤3 项，每项要有可验证的假设）
1. 假设：<把 X 从 A 改到 B> → 预期 <指标> 提升 <幅度>
   验证方式：<怎么测>   观察期：<多久>
2. ...

## 不改的（明确写出来）
- <看起来能优化但不是瓶颈的事> —— 现在做是浪费
```

**纪律**：
- 一次只改**一个**变量，否则不知道哪个起作用（同 `product-validation`）。
- 每项改动都要**先有假设**，再动手。
- 明确写出**不做什么**——这比要做什么更重要。

## 七、反模式清单

1. **上线后才发现没埋点。** → 白白浪费第一批最贵的用户。
2. **盯 10 个指标。** → 等于没有指标。
3. **只看总量不看队列。** → 拉新掩盖留存崩坏。
4. **把 PV/注册数当北极星。** → 它们不反映价值。
5. **优化不是瓶颈的环节。** → 花费大量精力，指标不动。
6. **靠感觉判断渠道好坏。** → 必须算"留存后"的有效 CAC。
7. **一次改多个变量。** → 学不到任何东西。
8. **只分析不行动。** → 分析变自我娱乐。
9. **埋点塞敏感数据。** → 合规风险。
10. **把"增长"理解成"推广"。** → 留存才是底线，产品没抓住人时推广是烧钱。
