# 分诊标签（Triage Labels）

这些技能用五个规范的分诊角色来说话。本文件把这些角色映射到本仓库 issue 追踪器里**实际使用**的标签字符串。

| 本体系约定的标签 | 我们追踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完整规格化，可供离线 agent 接手 |
| `ready-for-human`          | `ready-for-human`    | 需要人来实现 |
| `wontfix`                  | `wontfix`            | 不会处理 |

当某个技能提到一个角色时（例如"打上 AFK-ready 分诊标签"），就使用本表中对应的标签字符串。
