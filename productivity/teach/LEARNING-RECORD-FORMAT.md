# 学习记录格式

学习记录位于 `./learning-records/`，按顺序编号：`0001-slug.md`、`0002-slug.md` 等。**惰性创建**目录——只有第一条记录要写时才建。

它们是教学领域的 ADR：捕获不明显的教训、关键洞见，以及用户明确声明的既有知识——这些会引导未来的会话。它们用来计算**最近发展区**。

## 模板

```md
# {学到或确立的东西的简短标题}

{1-3 句：学到了什么（或确立了哪些既有知识），以及它为什么影响未来的会话。}
```

这就是整个格式。一条学习记录可以只有一个段落。价值在于记录**这现在已知**、以及**它为什么改变接下来该教什么**——不在于把各个小节填满。

## 可选小节

只在确实增加价值时才包含。大多数记录用不上。

- **Status** frontmatter（`active | superseded by LR-NNNN`）—— 当早先的理解被证明是错的并被替换时有用。
- **Evidence（证据）** —— 用户如何展示了这份理解（回答了一个问题、完成了一个练习、提到了过往经验）。当这个主张可能被重新审视时有用。
- **Implications（影响）** —— 这对未来会话解锁或排除了什么。不明显时值得记录。

## 编号

扫一遍 `./learning-records/` 取现有最大编号，加一。

## 什么时候写一条学习记录

以下任一条成立时就写：

1. **用户展示了某件非平凡之事的真实理解** —— 不只是接触过，而是有证据表明他能正确使用这个概念。这为"接下来教什么"设定了新的下限。
2. **用户透露了既有知识** —— "我已经会 X 了。"记下来，免得未来会话重教。**也记录他声称的深度。**
3. **一个误解被纠正了** —— 用户先前相信了错的东西、现在明白了为什么。这些价值很高：它们能预测相关主题未来的绊脚石。
4. **使命因学习而移动了** —— 用户发现他真正在意的东西和原先以为的不一样。交叉链接到 [[MISSION.md]] 并更新它。

### 什么**不**算数

- 仅仅**覆盖过**的材料。覆盖不等于学习。**等证据。**
- 任何已经作为术语定义简洁记录在 [[GLOSSARY.md]] 里的东西。不要重复。
- 逐次会话的活动日志。学习记录不是日记——它们是**决策级的洞见**。

## 取代（Supersession）

当后来的记录与早先的某条矛盾时（用户的理解加深或被更正了），把旧记录标成 `Status: superseded by LR-NNNN`，而不是删除它。**理解如何演进的历史本身就是有用的信号。**
