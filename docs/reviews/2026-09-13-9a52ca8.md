### 这轮真机一共抓到我 7 个错（都记在案，因为它们说明了"为什么要真机跑"）
1. 自检用例的**期望写错**（跑闸门不带 `-IncludeTests` 却拿含 E1 的期望比对）
2. **变异选错字数**（单字中文数字 → 命中 0 处，红的是别的检查项）
3. **变异字符串过期**（写死的旧标题已不存在 → `replace` 静默返回原串 → 用例假红）
4. **通过语义写反**（变异用例里"护栏抓到 = 用例通过"，我写成了相反）
5. **断言了 PowerShell 输出里的中文** —— 真根因是**控制台代码页**（GBK/936）与
   `spawnSync(encoding:"utf8")` 不匹配，跟被测对象无关
6. **`-RuffLabel` 早退太晚**（整次调用去扫 WinGet/Python 目录 → 超时 2 分钟）
7. **静态断言没跟着代码搬家**（函数抽到 `ruff-label.ps1` 后旧断言仍在主文件里找它 → 假红；
   顺带发现"**没有任何检查断言主文件点源了它**"这个真缺口）

第 3 条直接催生了"变异必须真的改到东西"那道总闸；第 5 条写进行为验证协议第六节；
第 7 条说明**改动引入的新耦合需要新判据**。
